# Motivational Quotes ✨

A tiny Python script that sends or displays motivational quotes. 🎯

## Features 🚀
- Random quote selection
- Simple, lightweight script
- Easy to customize quotes

## Requirements 🧰
- Python 3.8+

## Setup ⚙️
1. (Optional) Create a virtual environment.
2. Make sure Python is installed.
3. Add your own quotes in `quotes.txt` (one per line).

## Run ▶️
```bash
python motivational_quotes.py
```

## Google App Password (Gmail) 🔐
Use these steps only if the app needs to send email via Gmail.

1. Go to Google Account settings: https://myaccount.google.com/
2. Open **Security**.
3. Under **Signing in to Google**, turn on **2‑Step Verification** (required).
4. After 2‑Step Verification is enabled, return to **Security**.
5. Open **App passwords**.
6. In **Select app**, choose **Mail**. In **Select device**, choose **Other** and name it (e.g., "Motivational Quotes").
7. Click **Generate**.
8. Copy the 16‑character app password and use it in the script when prompted or in your config.

## Notes 📝
- Keep your app password private.
- If **App passwords** is not visible, verify 2‑Step Verification is enabled and your account is eligible.
