# Flashcard French → English 🃏🇫🇷➡️🇬🇧

A simple Tkinter flashcard app to practice French vocabulary and learn English translations. ✨

## Features 🚀
- Random French words on a flashcard
- Auto-flip to English after a short delay
- Mark words as learned ✅
- Progress saved to a local file 💾

## Requirements 🧰
- Python 3.8+
- Tkinter (bundled with standard Python on most systems)

## How to Run ▶️
1. Open a terminal in this folder.
2. Run:
   - Windows: `python main.py`
   - macOS/Linux: `python3 main.py`

## Data Files 📁
- `data/french_words.csv` — original word list
- `data/words_to_learn.csv` — your saved progress

## Notes 📝
- If `words_to_learn.csv` doesn’t exist, the app will start from the original list.
- You can delete `words_to_learn.csv` to reset progress.

Happy learning! 🎯
