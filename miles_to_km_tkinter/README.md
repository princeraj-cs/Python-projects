# Miles to Km Converter (Tkinter)

A simple Tkinter GUI that converts miles to kilometers.

## Features
- Lightweight desktop GUI
- Instant conversion (miles 609)

## Requirements
- Python 3.x
- Tkinter (included with most Python installations)

## Run
From the project folder:

python converter.py

## How to Use
1. Enter a miles value.
2. Click **Calculate**.
3. Read the kilometers result.

## Notes
- Conversion uses: 1 mile = 1.609 km.
